# 本草堂微信小程序 · 上线指南

## 第一步：注册小程序

1. 打开 https://mp.weixin.qq.com
2. 点击「立即注册」→ 选择「小程序」
3. 用未注册过公众号/小程序的邮箱注册
4. 选择「企业」类型，提交营业执照
5. 认证费 300元/年
6. 获取 AppID

## 第二步：配置小程序

1. 打开 `project.config.json`
2. 将 `"appid": "YOUR_APPID_HERE"` 替换为你的 AppID
3. 在小程序后台「开发管理」→「开发设置」：
   - 服务器域名 → request合法域名 添加你的网站域名
   - 业务域名 添加你的网站域名（web-view 必须）

## 第三步：上传代码

1. 下载微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开本项目 `miniprogram/` 目录
3. 点击「上传」→ 填写版本号 → 上传

## 第四步：提交审核

1. 小程序后台 → 版本管理
2. 选择开发版本 → 提交审核
3. 审核通过后点击「发布」

## 第五步：获取小程序码

发布后在小程序后台「设置」→「基本设置」下载小程序码。

## 当前配置

- 网站地址：http://172.20.21.34:8501（部署到服务器后需换成 HTTPS 域名）
- web-view 会自动打开网站版本草堂

## ⚠️ 重要提醒

- 微信小程序要求服务器必须使用 **HTTPS**
- web-view 加载的域名必须在后台配置为**业务域名**
- 小程序中的 web-view 无法使用本地 IP（172.20.x.x），必须绑定已备案域名
