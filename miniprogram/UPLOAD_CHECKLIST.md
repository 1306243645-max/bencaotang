# 妙手堂小程序 · 上传审核清单

## 准备工作

### 1. 获取 AppID
1. 登录 https://mp.weixin.qq.com
2. 左侧菜单 → 开发 → 开发管理 → 开发设置
3. 复制 AppID（格式：wxXXXXXXXXXXXXXXXX）
4. 替换 `project.config.json` 中的 `"YOUR_APPID_HERE"`

### 2. 小程序信息填写
在微信公众平台 → 设置 → 基本设置：
- 名称：妙手堂中医
- 简介：AI智能中医问诊 · 体质自测 · 舌诊面诊 · 养生商城
- 类目：医疗 > 健康管理服务平台
- 头像：上传诊所 Logo（建议 144×144px PNG）

### 3. 上传前检查

- [ ] `project.config.json` 中 appid 已设置
- [ ] 所有 5 个 Tab 页面完整（index/consult/experts/shop/mine）
- [ ] Tab 图标文件存在（10 张 PNG）
- [ ] 无 console.log 调试代码
- [ ] `app.json` 页面路径正确
- [ ] 内容不含敏感词/医疗承诺

### 4. 上传步骤

```
1. 打开 微信开发者工具
2. 导入项目 → 选择 miniprogram/ 目录
3. 填入 AppID
4. 点击「编译」→ 检查无报错
5. 点击「预览」→ 手机扫码测试
6. 点击「上传」→ 填写版本号 v1.0.0 + 备注
7. 登录 mp.weixin.qq.com → 版本管理
8. 选择刚上传的版本 → 提交审核
```

### 5. 审核注意事项

- 医疗类目需提供《医疗机构执业许可证》或其他资质
- 如无资质，建议改为「健康管理」类目
- AI 问诊内容必须标注「仅供参考，不构成医疗建议」
- 商品功能若涉及支付需申请微信支付
- 首次审核通常 1-7 个工作日
