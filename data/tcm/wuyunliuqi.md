# 毛小妹 · 五运六气学说

> 五运六气 (Wu Yun Liu Qi / Five Movements and Six Qi)
> 源自《黄帝内经·素问》运气七篇，是中医天人合一思想的巅峰理论。
> 毛小妹老师是现代五运六气研究的代表人物，创立「毛氏运气医学」体系。

---

## 一、五运六气基础

### 五运 (Five Movements / 五运)

五运是地球气候的五年周期律，由天干决定。

| 天干 | 五运 | 太过/不及 | 气候特点 | 易病脏腑 |
|------|------|-----------|----------|----------|
| 甲 | 土运 | 太过 | 湿气重 | 脾、肾 |
| 乙 | 金运 | 不及 | 燥气不足 | 肺、肝 |
| 丙 | 水运 | 太过 | 寒气重 | 肾、心 |
| 丁 | 木运 | 不及 | 风气不足 | 肝、肺 |
| 戊 | 火运 | 太过 | 热气重 | 心、肾 |
| 己 | 土运 | 不及 | 湿气不足 | 脾、肝 |
| 庚 | 金运 | 太过 | 燥气重 | 肺、肝 |
| 辛 | 水运 | 不及 | 寒气不足 | 肾、脾 |
| 壬 | 木运 | 太过 | 风气重 | 肝、脾 |
| 癸 | 火运 | 不及 | 热气不足 | 心、肺 |

**推算口诀**：甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火
- 阳干（甲丙戊庚壬）为**太过**
- 阴干（乙丁己辛癸）为**不及**

## 二、毛小妹运气医学核心观点

### 1. 「天人合一」的体质观
毛小妹认为，人的体质不是固定不变的"九种体质"，而是在**出生时的运气格局**基础上，随着每年运气变化而动态调整的。

**核心公式**：
> 当下体质 = 出生运气格局 + 当下运气影响 + 生活方式累积

### 2. 出生年份定体质基调
根据出生年份的天干地支，可以判断一个人的**先天体质倾向**：

- **木运年出生**（丁、壬年）：肝胆系统偏弱，易肝郁
- **火运年出生**（戊、癸年）：心脑血管偏弱，易心火旺
- **土运年出生**（甲、己年）：脾胃系统偏弱，易湿困
- **金运年出生**（乙、庚年）：肺系统偏弱，易燥咳
- **水运年出生**（丙、辛年）：肾系统偏弱，易寒凝

### 3. 每年运气影响
每年根据当年的天干地支推算**岁运+司天在泉**，预测当年的：
- 气候特点
- 易发疾病
- 养生要点
- 饮食宜忌

### 4. 「运气方」的临床运用
毛小妹创制了一系列**基于运气的调理方**：
- 根据当年运气特点调整基础方剂
- 结合患者出生运气个性化用药
- 强调「因时制宜」高于「因人制宜」

### 5. 毛氏「三因制宜」升级版
| 传统 | 毛氏升级 |
|------|----------|
| 因时制宜 | 以运气推算为主 |
| 因地制宜 | 考虑南北半球差异 |
| 因人制宜 | 出生运气+当下运气 |

## 三、2026 年运气分析（丙午年）

### 岁运
**丙午年**：丙为**水运太过**，午为**少阴君火司天**

> 2026年是「水运太过+君火司天」之年 = **寒气偏重 + 上半年偏热**

### 全年气候特点
- 水运太过 → 全年寒气偏重，冬季更冷
- 少阴君火司天 → 上半年（大寒→大暑）偏热
- 阳明燥金在泉 → 下半年（大暑→大寒）偏燥

### 2026 年易发疾病
| 时段 | 易发病 |
|------|--------|
| 上半年 | 心火旺 → 失眠、口疮、心悸 |
| 下半年 | 肺燥 → 干咳、便秘、皮肤干燥 |
| 全年 | 寒+热交替 → 外寒内热感冒、关节痛 |

### 2026 年养生要点
- **上半年**：清心火，多吃苦味（苦瓜、莲子心），少辛辣
- **下半年**：润肺燥，多吃梨、百合、银耳，少吃燥热食物
- **全年**：注意保暖，尤其腰腹部和关节

## 五、毛小妹运气养生法

### 1. 根据出生年选择日常饮食
- **木运年出生**（肝胆弱）→ 多吃绿色蔬菜、枸杞、菊花
- **火运年出生**（心火弱/旺）→ 红黑食材、莲子、桂圆
- **土运年出生**（脾胃弱）→ 黄色食材、小米、山药、茯苓
- **金运年出生**（肺弱）→ 白色食材、梨、百合、银耳
- **水运年出生**（肾弱）→ 黑色食材、黑芝麻、黑豆、核桃

### 2. 根据当年运气调整养生策略
每年大寒后，根据新一年的天干地支推算岁运和司天在泉，调整：
- 饮食方案
- 运动方式
- 穴位保健重点
- 情绪调节方向

### 3. 「运气针法」穴位选择
根据当年运气选择**五输穴**进行保健：
- 木运年 → 重点取肝经**大敦、行间、太冲**
- 火运年 → 重点取心经**少府、神门**、心包经**大陵**
- 土运年 → 重点取脾经**太白、阴陵泉**、胃经**足三里**
- 金运年 → 重点取肺经**太渊、尺泽**
- 水运年 → 重点取肾经**太溪、阴谷**

### 4. 毛小妹「节气养生」要点
- **大寒**：全年运气转换点，开始按新年运气养生
- **春分**：二之气开始，注意清肝火
- **小满**：三之气（司天主气）开始，全年最重要的养生节点
- **大暑**：四之气开始，从上半年模式切换到下半年模式
- **秋分**：五之气开始，润燥养肺
- **小雪**：终之气开始，温养闭藏

## 六、实用查询流程

问诊时运用五运六气：

1. **问出生年份** → 查表确定先天运气体质
2. **看当下年份** → 推算当年岁运+司天在泉
3. **结合症状** → 判断是先天体质问题还是当年运气影响
4. **给建议** → 运气食疗+运气穴位+运气生活方式

### 示例
患者 1990 年出生（庚午年：金太过+君火司天），2026 年（丙午：水太过+君火司天）就诊。

- 先天：金太过 → 肺燥体质，易干咳、皮肤干
- 当下：水太过 → 寒气重，君火司天 → 上半年心火旺
- 综合：肺燥+心火+肾寒，需润肺清心温肾
- 食疗：梨+百合（润肺），莲子心（清心），核桃（温肾）
