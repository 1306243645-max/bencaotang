### 澳洲特别提示
澳洲在南半球，季节与中国相反。使用本系统时：
- 中国夏季 → 澳洲冬季：用冬季茶材
- 中国冬季 → 澳洲夏季：用夏季茶材
- 澳洲干燥地区多，全年注意加润肺茶材

## 五、一人一方生成流程

### 问茶三步

**第一步：问出生**
- 出生年份 → 天干地支 → 基础茶底 + 司天调和

**第二步：看当下**
- 当前日期 → 对应节气 → 时令加材
- 当前所在地 → 地域调和

**第三步：出茶方**
- 基础茶底 + 司天调和 + 时令加材 + 地域调和 = 今日专属茶

### 实例演示

**例1：1990年生人，2026年6月16日，在济南**

1. 出生：庚午年 → 金运太过（基础：润肺） + 君火司天（调和：清心）
2. 当前：芒种节气（时令：绿豆） + 济南/中部（地域：山药）
3. 茶方：**银耳百合茶 + 绿豆 + 山药**
   - 配方：银耳半朵 + 百合10g + 绿豆10g + 山药15g + 冰糖
   - 泡法：银耳泡发，同煮30分钟
   - 功效：润肺清心、解暑健脾

**例2：1988年生人，2026年12月22日（冬至），在哈尔滨**

1. 出生：戊辰年 → 火运太过（基础：清心） + 寒水司天（调和：温阳）
2. 当前：冬至（时令：人参须） + 东北（地域：人参）
3. 茶方：**桂圆红枣茶 + 人参须 + 肉桂**
   - 配方：桂圆8颗 + 红枣5颗 + 人参须3g + 肉桂1片
   - 泡法：煮15分钟
   - 功效：温阳补气、养心安神

**例3：1995年生人，2026年7月（小暑），在悉尼**

1. 出生：乙亥年 → 金运不及（基础：补肺） + 风木司天（调和：疏风）
2. 南半球7月=中国1月=小寒（时令：制附子→澳洲替换为生姜肉桂）
3. 澳洲（地域：全年润肺）
4. 茶方：**黄芪百合茶 + 生姜肉桂 + 薄荷**
   - 配方：黄芪10g + 百合10g + 生姜5片 + 肉桂1小片 + 薄荷3片
   - 泡法：煮10分钟
   - 功效：补肺温阳（澳洲冬季专属）
