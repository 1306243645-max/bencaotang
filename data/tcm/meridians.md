## 穴位定位参考图 (Measurement: Cun / 寸)

```
1 cun = width of your thumb at the interphalangeal joint
1.5 cun = width of your index + middle fingers together
3 cun = width of all four fingers together (excluding thumb)
```

## 常用穴位组合 (Common Point Combinations)

### Insomnia
- **HT7 (Shen Men)** + **SP6 (San Yin Jiao)** + **Yin Tang**
- If liver fire: add **LV3 (Tai Chong)**
- If heart-kidney disharmony: add **KI3 (Tai Xi)** + **KI1 (Yong Quan)**

### Stress / Irritability
- **LV3 (Tai Chong)** + **LI4 (He Gu)** — "Four Gates" combo
- Add **PC6 (Nei Guan)** for chest tightness
- Add **GB20 (Feng Chi)** for tension headache

### Digestive Weakness / Bloating
- **ST36 (Zu San Li)** + **SP6 (San Yin Jiao)** + **CV12 (Zhong Wan)**
- If dampness: add **ST40 (Feng Long)**

### Headaches
- General: **LI4 (He Gu)** + **Tai Yang** + **GB20 (Feng Chi)**
- Frontal: add **Yin Tang**
- Temporal: add **Tai Yang** + **LV3 (Tai Chong)**
- Occipital: add **GB20 (Feng Chi)** + **BL60 (Kun Lun, behind lateral malleolus)**

### Fatigue / Low Energy
- **ST36 (Zu San Li)** + **CV6 (Qi Hai)** + **KI3 (Tai Xi)**
- With brain fog: add **ST40 (Feng Long)** + **DU20 (Bai Hui)**

### Menstrual Issues
- **SP6 (San Yin Jiao)** + **LV3 (Tai Chong)** + **CV4 (Guan Yuan)**
- PMS with irritability: add **PC6 (Nei Guan)**
- Pain: add **SP10 (Xue Hai)**

### Neck / Shoulder Tension
- **GB20 (Feng Chi)** + **GB21 (Jian Jing, on top of shoulder)** + **LI4 (He Gu)**

## Self-Acupressure Guidelines

1. Find a comfortable seated or lying position
2. Locate the point — you may feel a slight depression or tenderness
3. Apply firm but comfortable pressure with thumb or index finger
4. Hold for 1-2 minutes, breathe deeply
5. Can repeat 2-3 times daily
6. Avoid pressure on broken skin, varicose veins, or areas of inflammation
7. If pregnant: avoid LI4, SP6, GB21 unless under practitioner guidance
