## 课程一：人体气象站基础

### 1.1 什么是人体气象站

人体气象站是毛小妹老师提出的核心理念：**人体内部有一个完整的气候系统**，它能够感知、记录、并响应天地间的五运六气变化。

| 天地气象 | 人体气象站 | 对应关系 |
|----------|-----------|----------|
| 风 | 肝 | 肝主疏泄，如风之动 |
| 热/火 | 心 | 心主血脉，如日之温 |
| 湿 | 脾 | 脾主运化，如土之润 |
| 燥 | 肺 | 肺主宣发，如金之敛 |
| 寒 | 肾 | 肾主封藏，如水之凝 |

### 1.2 人体气象站的三大功能

**1. 感知功能（Sensor）**
- 经络系统是散布全身的传感器
- 365 个穴位是气象数据采集点
- 五脏六腑是中央处理器

**2. 记录功能（Memory）**
- 出生时的运气格局刻入先天体质
- 每年的运气变化写入经络
- 疾病是气象异常的"日志文件"

**3. 预测功能（Forecast）**
- 根据出生运气推断先天弱点
- 根据当年运气预测易发病
- 节气交替时是"气象预警期"

### 1.3 人体气象站的运转周期

| 周期 | 时间 | 对应系统 | 养生要点 |
|------|------|----------|----------|
| 日周期 | 24小时 | 子午流注 | 按时作息 |
| 旬周期 | 10天 | 天干轮转 | 五行交替 |
| 月周期 | 30天 | 月相盈亏 | 气血盛衰 |
| 季周期 | 90天 | 五运更迭 | 五脏调养 |
| 年周期 | 365天 | 六气司天 | 全年养生 |
| 甲子周期 | 60年 | 干支轮回 | 生命节律 |

## 课程二：出生密码——你的先天运气档案

### 2.1 出生年月解码

每个人出生时的五运六气格局，就像一份**先天体质档案**，记录了：
- 当年岁运（天干决定）→ 五脏强弱偏颇
- 当年司天（地支决定）→ 上半年易感外邪
- 当年在泉（地支决定）→ 下半年身体趋势

**解码公式**：
```
出生年天干 → 岁运（五行+太过/不及）
出生年地支 → 司天之气 + 在泉之气
```

### 2.2 实例分析

**例1：1984年（甲子年）出生**
- 甲 → 土运太过 → 脾胃系统偏湿
- 子 → 少阴君火司天 → 上半年心火偏旺
- 午 → 阳明燥金在泉 → 下半年肺燥
- **先天体质**：脾湿+心火+肺燥的混合体质
- **养生重点**：健脾祛湿、清心安神、润肺

**例2：1995年（乙亥年）出生**
- 乙 → 金运不及 → 肺系统偏弱
- 亥 → 厥阴风木司天 → 上半年肝风偏盛
- 巳 → 少阳相火在泉 → 下半年火气偏旺
- **先天体质**：肺弱+肝旺+火盛的混合体质
- **养生重点**：补肺气、平肝、清热

### 2.3 出生月份微调

在年运格局基础上，出生月份进一步细化：
- 生于上半年（大寒→大暑）：司天之气影响更大
- 生于下半年（大暑→大寒）：在泉之气影响更大
- 生于三之气（小满→大暑）：司天之气达到顶峰

## 课程四：节气气象站——24 节气的人体响应

### 4.1 节气交替是「气象预警」

毛小妹强调：**每个节气交替的前后三天，是人体气象站的「预警窗口期」**。

| 关键节气 | 人体响应 | 养生要点 |
|----------|----------|----------|
| 大寒 | 全年运气转换点 | 开始按新年运气养生 |
| 春分 | 阴阳平分 | 注意肝气升发 |
| 夏至 | 阳极生阴 | 清心火、养心阴 |
| 秋分 | 阴阳再平分 | 润燥养肺 |
| 冬至 | 阴极生阳 | 温补阳气 |

### 4.2 节气经络开合

每个节气对应一条经络的「开」或「合」：
- 立春 → 肝经开
- 春分 → 胆经开
- 立夏 → 心经开
- 夏至 → 小肠经开
- 立秋 → 肺经开
- 秋分 → 大肠经开
- 立冬 → 肾经开
- 冬至 → 膀胱经开

在对应节气调理对应经络，事半功倍。

## 课程五：人体气象站诊断法

### 5.1 三步诊断法

**第一步：看出生**
- 问出生年月日 → 查五运六气表 → 定先天体质

**第二步：看当下**
- 问发病时间 → 查当年运气 → 看六气时段

**第三步：看症状**
- 症状对应脏腑 → 结合运气 → 确定证型

### 5.2 案例分析

**案例：35岁女性，2026年3月就诊，主诉严重失眠**

1. 出生：1990年（庚午年）
   - 庚=金太过，午=君火司天
   - 先天：金燥+火旺体质

2. 当下：2026年3月
   - 丙午年，初之气→二之气交替
   - 客气太阳寒水→厥阴风木
   - 风火相煽+外寒束缚

3. 症状：失眠、口干、心烦
   - 先天火旺+当下风火激发
   - 外寒束缚，内热无法发散

**结论**：先天心火体质 + 2026君火司天 + 节气交替风火激发 = 严重失眠

**方案**：
- 清心火：莲子心+竹叶茶
- 散外寒：生姜泡脚
- 按太冲+神门
- 大寒后开始按2026年运气养生

### 6.2 运气食疗方

根据当年运气调整饮食：

**2026 丙午年通用食疗方**：

## 课程七：人体气象站与疾病预测

### 7.1 疾病发生的气象条件

| 疾病 | 气象条件 | 高发时段 |
|------|----------|----------|
| 感冒 | 客气+主气相克 | 节气交替 |
| 失眠 | 火气偏旺 | 三之气 |
| 关节痛 | 寒湿叠加 | 终之气 |
| 消化问题 | 湿土太过 | 四之气 |
| 皮肤问题 | 风+燥 | 初之气、五之气 |
| 心脑血管 | 寒热交替 | 大寒、夏至 |

### 7.2 预防先于治疗

毛小妹强调：**五运六气最大的价值是「治未病」**。

- 知道当年运气 → 提前预防
- 知道自身体质 → 针对调理
- 知道节气交替 → 提前防护
- 知道六气变化 → 分段养生

## 课程八：人体气象站与现代生活

### 8.1 现代人的「气象紊乱」

| 现代行为 | 气象影响 |
|----------|----------|
| 熬夜 | 打乱子午流注，相当于天天跨时区 |
| 空调 | 制造人工寒冬，夏季伤阳 |
| 冷饮 | 直接扑灭脾胃之火 |
| 压力 | 长期肝气郁结 → 气滞血瘀 |
| 过度用眼 | 耗伤肝血 → 血不养筋 |

### 8.2 修复人体气象站的三步法

**第一步：归位**
- 按时作息，让子午流注正常运转
- 晚上11点前睡觉，早上7点前起床

**第二步：调频**
- 根据出生运气和当年运气调整饮食
- 在节气交替日进行经络调理

**第三步：升级**
- 每年大寒后更新当年的养生计划
- 根据年龄段调整养生策略（女七男八）
