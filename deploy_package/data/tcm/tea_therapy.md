# 本草堂 · 茶饮食疗库

> 以茶为药，以食为养。一杯茶汤，一份健康。

---

## 一、安神助眠茶

### 1. 酸枣仁安神茶
- **配方**：酸枣仁15g（捣碎）+ 百合10g + 茯苓10g
- **泡法**：酸枣仁捣碎，所有材料加水500ml煮10分钟，睡前1小时温饮
- **功效**：养心补肝、宁心安神
- **适合**：入睡困难、心慌多梦、肝血不足
- **味道**：微甘淡雅
- **禁忌**：实热便秘者慎用

### 2. 桂圆红枣安神茶
- **配方**：桂圆肉8颗 + 红枣5颗 + 枸杞10粒
- **泡法**：沸水300ml焖泡15分钟，可反复冲泡3次
- **功效**：补益心脾、养血安神
- **适合**：心脾两虚、健忘心悸、血虚失眠
- **味道**：甘甜温润
- **禁忌**：上火口疮时暂停

### 3. 玫瑰花安神茶
- **配方**：玫瑰花6朵 + 合欢花3g + 蜂蜜少许
- **泡法**：85°C水200ml冲泡5分钟，下午或傍晚饮用
- **功效**：疏肝解郁、安神定志
- **适合**：压力大、情绪低落、经前烦躁
- **味道**：花香怡人
- **禁忌**：孕妇慎用

### 4. 莲子心竹叶清心茶
- **配方**：莲子心3g + 淡竹叶5g + 冰糖少许
- **泡法**：沸水冲泡8分钟
- **功效**：清心火、除烦热
- **适合**：心烦失眠、口舌生疮、心火旺
- **味道**：微苦回甘
- **禁忌**：脾胃虚寒者少喝

## 二、清肝明目茶

### 5. 菊花枸杞明目茶
- **配方**：菊花5朵 + 枸杞15粒 + 决明子8g
- **泡法**：85°C水冲泡，焖5分钟
- **功效**：清肝明目、滋阴降火
- **适合**：眼干涩、视力模糊、熬夜后用眼过度
- **味道**：清雅微甘
- **禁忌**：脾胃虚寒腹泻者少喝

### 6. 桑叶菊花清肝茶
- **配方**：桑叶5g + 菊花3朵 + 薄荷3片
- **泡法**：沸水冲泡5分钟，夏季可加冰块
- **功效**：清肝明目、疏风散热
- **适合**：头痛目赤、风热感冒初起
- **味道**：清凉舒爽
- **禁忌**：风寒感冒不宜

### 7. 决明子山楂降脂茶
- **配方**：决明子10g + 山楂5片 + 荷叶3g
- **泡法**：沸水冲泡10分钟，饭后代茶饮
- **功效**：清肝明目、降脂通便
- **适合**：高血压、高血脂、便秘
- **味道**：微酸微苦
- **禁忌**：低血压、孕妇慎用

## 三、健脾祛湿茶

### 8. 陈皮茯苓祛湿茶
- **配方**：陈皮1瓣 + 茯苓10g + 薏米15g（炒黄）
- **泡法**：薏米干炒至微黄，所有材料加水400ml煮15分钟
- **功效**：健脾理气、祛湿化痰
- **适合**：脾虚湿重、饭后困倦、大便粘滞
- **味道**：橘香四溢
- **禁忌**：阴虚口干者少喝

### 9. 生姜红枣暖胃茶
- **配方**：生姜5片 + 红枣5颗 + 红糖1勺
- **泡法**：生姜红枣加水300ml煮8分钟，加红糖融化
- **功效**：温中散寒、暖胃止呕
- **适合**：胃寒腹痛、恶心呕吐、手脚冰凉
- **味道**：辛香甜暖
- **禁忌**：胃热口臭者不宜

### 10. 山药芡实健脾茶
- **配方**：山药15g（干品）+ 芡实10g + 莲子10g
- **泡法**：所有材料加水500ml煮15分钟，喝汤吃料
- **功效**：补脾止泻、益肾固精
- **适合**：脾虚泄泻、食欲不振
- **味道**：甘淡平和
- **禁忌**：便秘腹胀者少喝

### 11. 大麦消食茶
- **配方**：炒大麦20g + 山楂3片
- **泡法**：沸水冲泡10分钟，饭后饮用
- **功效**：消食化积、和胃健脾
- **适合**：吃撑了、肉食不消化
- **味道**：麦香浓郁
- **禁忌**：空腹不宜

## 四、补气养血茶

### 12. 黄芪当归补血茶
- **配方**：黄芪10g + 当归5g + 红枣5颗
- **泡法**：加水400ml煮沸转小火10分钟
- **功效**：补气生血、调经养颜
- **适合**：气血两虚、面色萎黄、月经量少
- **味道**：甘甜醇厚
- **禁忌**：感冒发热期间不宜

### 13. 党参桂圆补气茶
- **配方**：党参10g + 桂圆肉8颗 + 枸杞10粒
- **泡法**：沸水焖泡15分钟
- **功效**：补中益气、养血安神
- **适合**：气虚乏力、说话无力、易出汗
- **味道**：甘甜温润
- **禁忌**：实热证不宜

### 14. 五红补血茶
- **配方**：红枣5颗 + 枸杞10粒 + 红皮花生15粒 + 赤小豆20g + 红糖适量
- **泡法**：赤小豆提前泡2小时，加水煮30分钟，最后放红糖
- **功效**：补血养颜、益气健脾
- **适合**：贫血、面色苍白、经后调理
- **味道**：甘甜温暖
- **禁忌**：糖尿病控制红糖量

### 15. 黑芝麻核桃茶
- **配方**：黑芝麻15g（炒香磨粉）+ 核桃2颗 + 黑豆10g + 红茶3g
- **泡法**：黑豆煮水取汁，冲泡红茶+黑芝麻粉+核桃碎
- **功效**：补肾养血、乌发润肠
- **适合**：脱发白发、腰膝酸软、便秘
- **味道**：坚果香醇
- **禁忌**：腹泻者少喝

## 五、美容养颜茶

### 16. 玫瑰柠檬养颜茶
- **配方**：玫瑰花6朵 + 柠檬2片 + 蜂蜜1勺
- **泡法**：85°C水冲泡玫瑰花，降温后加柠檬和蜂蜜
- **功效**：疏肝解郁、美白淡斑
- **适合**：面色暗沉、色斑、情绪不佳
- **味道**：酸甜花香
- **禁忌**：胃酸过多者少喝

### 17. 银耳雪梨润肤茶
- **配方**：银耳半朵 + 雪梨半个 + 枸杞10粒 + 冰糖
- **泡法**：银耳泡发撕碎，雪梨切块，慢炖30分钟
- **功效**：滋阴润肺、美容养颜
- **适合**：皮肤干燥、干咳、阴虚
- **味道**：清甜润滑
- **禁忌**：风寒咳嗽不宜

### 18. 桃花养颜茶
- **配方**：干桃花3g + 蜂蜜1勺 + 柠檬1片
- **泡法**：85°C水150ml冲泡桃花5分钟，加蜂蜜柠檬
- **功效**：活血养颜、淡化色斑
- **适合**：面色暗沉、色斑
- **味道**：花香淡雅
- **禁忌**：孕妇禁用；月经量多者经期暂停

### 19. 薏仁美白茶
- **配方**：薏米20g + 杏仁10g + 牛奶100ml
- **泡法**：薏米杏仁煮水取汁，兑入温热牛奶
- **功效**：美白祛斑、利水消肿
- **适合**：皮肤暗黄、水肿
- **味道**：奶香杏仁
- **禁忌**：孕妇慎用；干性皮肤加蜂蜜

## 六、四季养生茶

### 20. 春·疏肝升阳茶
- **配方**：玫瑰花5朵 + 薄荷5片 + 枸杞10粒
- **泡法**：85°C水冲泡5分钟
- **功效**：疏肝理气、升发阳气
- **适合**：春季养生、情绪低落
- **味道**：清香提神

### 21. 夏·清暑祛湿茶
- **配方**：绿豆30g + 菊花5朵 + 薄荷5片 + 冰糖
- **泡法**：绿豆煮水取汁，冲泡菊花薄荷
- **功效**：清热解暑、祛湿利尿
- **适合**：夏季暑热、口干舌燥
- **味道**：清凉爽口

### 22. 秋·润肺生津茶
- **配方**：雪梨半个 + 百合10g + 银耳半朵 + 冰糖
- **泡法**：炖煮30分钟
- **功效**：滋阴润肺、生津止渴
- **适合**：秋燥干咳、皮肤干燥
- **味道**：清甜润滑

### 23. 冬·温阳暖身茶
- **配方**：肉桂1小片 + 生姜5片 + 红枣5颗 + 红糖
- **泡法**：煮10分钟
- **功效**：温阳散寒、暖身驱寒
- **适合**：冬季怕冷、手脚冰凉
- **味道**：辛香甘暖

## 七、减肥消脂茶

### 24. 荷叶山楂减肥茶
- **配方**：荷叶5g + 山楂5片 + 决明子8g
- **泡法**：沸水冲泡10分钟，饭前30分钟喝
- **功效**：降脂减肥、消食化积
- **适合**：肥胖、高血脂、便秘
- **味道**：微酸清爽
- **禁忌**：低血压、孕妇、胃酸过多慎用

### 25. 普洱茶消脂茶
- **配方**：普洱茶5g + 陈皮1瓣
- **泡法**：沸水冲泡，可反复冲泡5-8次
- **功效**：消食去腻、降脂减肥
- **适合**：吃油腻后、饭后消食
- **味道**：陈香醇厚
- **禁忌**：空腹不喝浓茶

## 八、茶饮制作工具

### 基础工具
- 玻璃茶壶（观色）
- 养生壶（煮茶）
- 保温杯（焖泡）
- 滤网/茶漏

### 泡茶三要素
| 茶类 | 水温 | 时间 | 次数 |
|------|------|------|------|
| 花茶 | 85°C | 3-5分钟 | 2-3次 |
| 叶茶 | 90°C | 3-5分钟 | 3-5次 |
| 根茎果 | 100°C | 10-15分钟 | 1-2次 |
| 煮茶 | 100°C | 15-30分钟 | 1次 |

## 九、体质茶饮速查

| 体质 | 推荐茶饮 | 避免茶饮 |
|------|----------|----------|
| 平和质 | 所有茶饮适量 | 无特殊 |
| 气虚质 | 黄芪当归茶、党参桂圆茶 | 浓茶、苦寒茶 |
| 阳虚质 | 生姜红枣茶、肉桂暖身茶 | 绿茶、凉茶 |
| 阴虚质 | 银耳雪梨茶、百合莲子茶 | 辛辣温热茶 |
| 痰湿质 | 陈皮茯苓茶、荷叶山楂茶 | 甜腻厚味茶 |
| 湿热质 | 菊花决明茶、绿豆薏米茶 | 温补滋腻茶 |
| 气郁质 | 玫瑰花茶、薄荷茶 | 浓烈刺激茶 |
| 血瘀质 | 桃花养颜茶、山楂红糖茶 | 寒凉收涩茶 |
| 特禀质 | 黄芪防风茶、甘草茶 | 易过敏茶材 |
