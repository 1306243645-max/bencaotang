## 实践课一：学会推算任何一年的运气格局

### 🎯 技能目标
给你任意一个年份，能推算出：岁运 + 司天 + 在泉 + 全年气候特点

### 📝 动手练习

**第1步：定岁运（看天干）**

记住口诀：**甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火**

阳干（甲丙戊庚壬）→ 太过
阴干（乙丁己辛癸）→ 不及

```
练习1：2026年是___年，天干是___，岁运是___运___（太过/不及）
答案：2026年是丙午年，天干是丙，岁运是水运太过
```

```
练习2：2024年是___年，天干是___，岁运是___运___（太过/不及）
答案：2024年是甲辰年，天干是甲，岁运是土运太过
```

**第2步：定司天在泉（看地支）**

记住口诀：**子午少阴、丑未太阴、寅申少阳、卯酉阳明、辰戌太阳、巳亥厥阴**

司天管上半年，在泉管下半年，司天和在泉是一对：

| 地支对 | 司天 | 在泉 |
|--------|------|------|
| 子⇔午 | 少阴君火 | 阳明燥金 |
| 丑⇔未 | 太阴湿土 | 太阳寒水 |
| 寅⇔申 | 少阳相火 | 厥阴风木 |
| 卯⇔酉 | 阳明燥金 | 少阴君火 |
| 辰⇔戌 | 太阳寒水 | 太阴湿土 |
| 巳⇔亥 | 厥阴风木 | 少阳相火 |

```
练习3：2026年是午年，司天是___，在泉是___
答案：司天是少阴君火，在泉是阳明燥金
```

**第3步：综合分析**

```
练习4：综合分析 2026 丙午年
- 岁运：水运太过 → 全年寒气偏重
- 司天：少阴君火 → 上半年（大寒→大暑）心火偏旺
- 在泉：阳明燥金 → 下半年（大暑→大寒）肺燥明显
- 运气相合：水克火 → 外寒内热格局
- 全年关键词：寒、热交替，防外寒内热
```

### ✏️ 课后作业
推算你出生那年的运气格局，并写出你的先天体质特点。

## 实践课二：出生体质诊断实操

### 🎯 技能目标
根据一个人的出生年月，判断其先天体质倾向和易病系统。

### 📝 案例练习

**案例1：1988年5月出生（戊辰年·生于上半年）**

推算步骤：
1. 戊 → 火运太过 → 心火偏旺
2. 辰 → 太阳寒水司天 → 上半年寒气
3. 戌 → 太阴湿土在泉 → 下半年湿气
4. 生于5月（上半年）→ 司天寒气影响更大

结论：
- 先天体质：心火旺 + 寒湿体质的混合
- 易病系统：心血管、脾胃
- 养生方向：清心火 + 温阳祛湿

**案例2：2001年11月出生（辛巳年·生于下半年）**

推算步骤：
1. 辛 → 水运不及 → 肾气偏弱
2. 巳 → 厥阴风木司天 → 上半年多风
3. 亥 → 少阳相火在泉 → 下半年火气
4. 生于11月（下半年）→ 在泉火气影响更大

结论：
- 先天体质：肾弱 + 上火下寒
- 易病系统：肾、肝
- 养生方向：温肾 + 清热

## 实践课五：经络气象自测

### 🎯 技能目标
通过按压特定穴位，探测脏腑的「气象异常」。

### 穴位按压自测法

每天按压以下穴位，记录敏感度（0=不痛 1=微酸 2=明显酸痛 3=刺痛）：

| 穴位 | 对应脏腑 | 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|------|----------|------|------|------|------|------|------|------|
| 太冲 LV3 | 肝 | | | | | | | |
| 神门 HT7 | 心 | | | | | | | |
| 足三里 ST36 | 脾胃 | | | | | | | |
| 太渊 LU9 | 肺 | | | | | | | |
| 太溪 KI3 | 肾 | | | | | | | |

### 📊 解读
- 某个穴位长期 2-3 分 → 对应脏腑有隐患
- 某个穴位突然从 0 变 2-3 → 该脏腑正在受外邪
- 所有穴位都低分 → 身体状态良好
