## 症状→证型映射表

### 头部
| 症状 | 可能证型 | 鉴别要点 |
|------|----------|----------|
| 前额头痛 | 阳明经头痛 | 伴有胃胀、便秘 |
| 两侧头痛 | 少阳经头痛 | 伴有口苦、目眩 |
| 头顶痛 | 厥阴经头痛 | 伴有干呕、吐涎沫 |
| 后脑痛 | 太阳经头痛 | 伴有项背僵硬、怕冷 |
| 全头沉重 | 痰湿头痛 | 如裹湿布、昏沉 |
| 头晕目眩 | 肝阳上亢 | 伴有耳鸣、急躁 |
| 头晕乏力 | 气血两虚 | 伴有面色苍白、心悸 |

### 面部/五官
| 症状 | 可能证型 | 鉴别要点 |
|------|----------|----------|
| 面色红 | 实热 / 虚阳上浮 | 实热：满面通红；虚阳：颧红如妆 |
| 面色黄 | 脾虚湿盛 / 黄疸 | 萎黄=脾虚；鲜明=阳黄；晦暗=阴黄 |
| 面色白 | 血虚 / 阳虚 | 苍白=血虚；晄白浮肿=阳虚 |
| 面色黑 | 肾虚 / 血瘀 | 晦暗=肾阳虚；黧黑=瘀血 |
| 眼干涩 | 肝血不足 / 阴虚 | 伴有视力模糊 |
| 眼红肿 | 肝火上炎 | 伴有口苦、烦躁 |
| 口苦 | 肝胆湿热 / 肝火 | 晨起口苦明显 |
| 口臭 | 胃火 / 食积 | 胃火：口臭+牙龈肿；食积：酸腐味 |
| 口疮 | 心火上炎 / 阴虚火旺 | 舌尖红=心火；反复发作=阴虚 |

### 睡眠
| 症状 | 可能证型 | 鉴别要点 |
|------|----------|----------|
| 入睡困难 | 心火旺 / 肝郁化火 | 心烦意乱、思绪多 |
| 凌晨1-3点醒 | 肝火扰心 | 肝经当令时段 |
| 凌晨3-5点醒 | 肺气虚 / 肺热 | 肺经当令时段 |
| 多梦易醒 | 心脾两虚 | 伴有心悸、健忘 |
| 彻夜不眠 | 痰热扰心 | 伴有胸闷、口苦 |
| 嗜睡 | 痰湿困脾 | 醒来仍困、头重 |

### 消化
| 症状 | 可能证型 | 鉴别要点 |
|------|----------|----------|
| 饭后腹胀 | 脾气虚 | 伴有乏力、大便稀 |
| 胃痛空腹加重 | 脾胃虚寒 | 得温痛减 |
| 胃痛饭后加重 | 食积 | 伴有嗳腐吞酸 |
| 反酸烧心 | 肝胃不和 | 情绪波动诱发 |
| 恶心呕吐 | 湿困脾胃 / 肝气犯胃 | 湿：呕吐清水；肝：呕吐酸苦 |
| 便秘干结 | 燥热内结 / 阴虚 | 燥热：腹胀痛；阴虚：羊粪状 |
| 腹泻水样 | 寒湿困脾 | 腹痛肠鸣 |
| 大便粘滞 | 湿热下注 | 里急后重 |

### 妇科
| 症状 | 可能证型 | 鉴别要点 |
|------|----------|----------|
| 经前乳胀 | 肝气郁结 | 情绪波动加重 |
| 痛经冷痛 | 寒凝血瘀 | 得热痛减、血块 |
| 痛经胀痛 | 气滞血瘀 | 经前开始、经行通畅后减轻 |
| 经期提前 | 血热 / 气虚 | 血热：量多色红；气虚：量多色淡 |
| 经期推后 | 血寒 / 血虚 | 血寒：量少有块；血虚：量少色淡 |
| 月经量少 | 血虚 / 肾虚 | 血虚：色淡；肾虚：腰酸 |
| 带下黄稠 | 湿热下注 | 瘙痒+异味 |
| 带下清稀 | 脾肾阳虚 | 无味+腰酸 |

### 全身
| 症状 | 可能证型 | 鉴别要点 |
|------|----------|----------|
| 怕冷 | 阳虚 | 全身怕冷、四肢不温 |
| 怕热 | 阴虚火旺 / 实热 | 阴虚：手心热；实热：全身热 |
| 自汗（白天出汗）| 气虚 | 动则汗出 |
| 盗汗（夜间出汗）| 阴虚 | 醒后汗止 |
| 手抖 | 肝风内动 / 血虚生风 | 肝风：+头晕；血虚：+麻木 |
| 腿抽筋 | 肝血不足 | 夜间多发 |
| 关节痛游走 | 风邪 | 位置不固定 |
| 关节痛固定 | 寒湿 / 血瘀 | 寒湿：冷痛；血瘀：刺痛 |

## Agent 使用指南

1. 接收用户症状描述
2. 对照本表初步判断可能证型
3. 追问鉴别要点确认
4. 用五运六气分析先天+当年影响
5. 输出综合辨证+个性化方案
